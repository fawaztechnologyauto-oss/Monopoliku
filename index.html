Kenapa Tidak Perlu Spreadsheet ID?

Di Apps Script (`Code.gs`), perintah SpreadsheetApp.getActiveSpreadsheet() otomatis terhubung ke Spreadsheet tempat script dibuat. Jadi **ID tidak diperlukan di JavaScript frontend**.

*(Opsional)* Jika kamu menggunakan Spreadsheet lain secara terpisah, gunakan SpreadsheetApp.openById('ID_SPREADSHEET') di Code.gs kamu.
